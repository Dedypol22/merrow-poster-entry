# MERROW — The Poster for a Place That Isn't There

An entry for make.fun's [The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539) bounty.

MERROW is the town that sails on a whale: a lantern-lit town built along the back of a gentle whale, with a lighthouse on its peak, sailing a sunset sea. `render.py` (Pillow, local use only) draws the poster and saves it as `poster.png`; `main.py` (standard library only) writes it to `/output/entry.png`.
